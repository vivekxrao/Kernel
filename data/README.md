# Local data files

Place these generated files here:

- `Kernel_T_Statistic.tif`
- `Kernel_Damage_Mask.tif`
- `buildings.geojson`
- `scored_buildings.geojson`

These files are generated locally or downloaded from Earth Engine/OSM. They are intentionally not included in source control or the distributable ZIP. The startup and pipeline scripts reuse existing files; do not delete this folder when updating the project.
